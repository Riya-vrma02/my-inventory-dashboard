##  Overview
The **Smart Inventory & Sales Dashboard** is a full-stack web application designed for FMCG distributors and small retailers to efficiently manage inventory, track sales, and predict restocking needs using data-driven insights.

It replaces traditional Excel-based workflows with a real-time, intelligent dashboard.

---

##  Key Highlights
-  Real-time inventory tracking  
-  Advanced sales analytics  
-  ML-based demand forecasting  
-  Secure authentication (JWT)  
-  Interactive dashboards with charts  

---

## FMCG distributors face:
- High SKU volume management  
- Lack of real-time stock visibility  
- Manual and error-prone sales tracking  
- No predictive insights for restocking  

 This project solves these using automation + analytics + machine learning.

## 🛠️ Tech Stack

### Frontend
- React.js  
- Axios  
- Bootstrap / Material UI

### Backend
- Python (Flask)

### Database

---

##  Features

###  Admin Dashboard
- Add / Update / Delete products (SKU management)  
- Real-time stock monitoring  
- Supplier purchase tracking  

###  Sales Management
- Record daily/weekly/monthly sales  
- Upload sales via CSV  
- Sales insights:
  - Product-wise  
  - Category-wise  
  - Region-wise  
  - Salesperson-wise  

###  Smart Alerts
- Low-stock notifications  
- Automated restocking suggestions  

### Predictive Analytics
- Forecast demand using ML models  
- Identify peak sales periods  
- Visualize trends with charts
